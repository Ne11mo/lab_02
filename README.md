# Streamstats analyzer of csv and jsonl files
Программа потоково анализирует входной файл и составляет отчет
по нему
## Функционал
 - Чтение файлов csv и jsonl формата
 - Проверка наличия обязательных полей, их корректности и проверка временной метки
 - Потоковая обратка входных файлов с помощью генераторов
 - Обработка некорректных строк с помощью ```--skip-invalid``` и вывод ее номера в лог
 - Объединение статистики по нескольким файлам
 - Подсчет общего числа событий, количество событий по уровням и источникам
 - Определение первой и последней временной метки
 - Формирование json или csv отчета (по умолчанию json)
 - Поддержка пользовательских форматов через registry parser-функций
 - Поддержка чтения входных файлов весом более 500МБ
## Команды
основной функционал: ```python -m streamstats analyze [INPUT (path)] --format csv|jsonl (--output (path)) (--skip-invalid)```
